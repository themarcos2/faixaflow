# FaixaFlow

**From song list to USB drive.**

FaixaFlow helps music shops turn customer song lists into organized downloads. Paste a Gemini list or a YouTube link, choose a format and save the files in the customer's folder. Add more links while downloads continue.

## Download

**[Download for Windows (.exe)](https://github.com/themarcos2/faixaflow/releases/latest/download/FaixaFlow-Setup.exe)**

Version **1.2.1** · Windows 10/11 64-bit

Run the installer and open FaixaFlow. The installer is currently unsigned.

## How to use

1. Copy the prompt from **Photo → Gemini list** and use it with the customer's photo in Gemini.
2. Paste the response in FaixaFlow and enter the customer name.
3. Choose quality and folder organization.
4. Click **Download** or **Generate links**.

You can also paste individual YouTube video or playlist links, one per line.

## Features

- **Languages:** Portuguese, English and Spanish. Detects the Windows display language; manual choice is available under **More → Language / Idioma**.
- **Audio and video:** MP3 from 128 to 320 kbps; MP4 up to 1080p.
- **Live queue:** add selections during a download.
- **Organized folders:** by customer, genre, artist or playlist title.
- **Original order:** optional numbering follows the customer's list.
- **Pause and resume:** continue interrupted sessions.
- **USB delivery:** copy the completed files to a USB drive.

## Import lists

The **Import** menu supports TXT, CSV and JSON files, Spotify and eSound. Spotify imports track names to find matches on YouTube.

## Help

Open **More → Full manual** in the app. To report an error, use **More → Export diagnostics**. Original tool errors may retain their original language.

Use only content you are authorized to download.
