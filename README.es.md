# FaixaFlow

**De la lista de canciones a la memoria USB.**

FaixaFlow organiza el trabajo musical de tu tienda. Pega una lista de Gemini o un enlace de YouTube, elige el formato y guarda los archivos en la carpeta del cliente. Puedes añadir enlaces mientras las descargas continúan.

## Descargar

**[Descargar para Windows (.exe)](https://github.com/themarcos2/faixaflow/releases/latest/download/FaixaFlow-Setup.exe)**

Versión **1.2.0** · Windows 10/11 de 64 bits

Ejecuta el instalador y abre FaixaFlow. El instalador aún no tiene firma digital.

## Cómo usar

1. Copia el prompt de **Foto → lista de Gemini** y úsalo con la foto del cliente en Gemini.
2. Pega la respuesta en FaixaFlow e indica el cliente.
3. Elige calidad y organización de carpetas.
4. Pulsa **Descargar** o **Generar enlaces**.

También acepta enlaces de vídeos individuales y playlists de YouTube, uno por línea.

## Funciones

- **Idiomas:** portugués, inglés y español. Detecta el idioma de Windows; puedes elegirlo en **Más → Language / Idioma**.
- **Audio y vídeo:** MP3 de 128 a 320 kbps; MP4 hasta 1080p.
- **Cola continua:** añade selecciones durante la descarga.
- **Carpetas organizadas:** por cliente, género, artista o título de playlist.
- **Orden original:** numeración opcional para seguir la lista del cliente.
- **Pausar y continuar:** retoma sesiones interrumpidas.
- **Entrega USB:** copia los archivos terminados a una memoria USB.

## Importar listas

El menú **Importar** admite TXT, CSV y JSON, Spotify y eSound. Spotify importa nombres de pistas para buscar coincidencias en YouTube.

## Ayuda

Abre **Más → Manual completo**. Para informar de un error, usa **Más → Exportar diagnóstico**. Los errores originales de herramientas pueden conservar su idioma.

Usa solo contenido que tengas autorización para descargar.
